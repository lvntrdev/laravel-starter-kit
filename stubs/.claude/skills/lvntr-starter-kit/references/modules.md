# Built-in modules

> Reference detail for the `lvntr-starter-kit` skill — read on demand.

You don't build these — you extend or configure them. Module runtimes live in
the vendor package; take project ownership of one with `sk:eject {Domain}`.

### File Manager

- Pluggable contexts (e.g. `users.avatar`, `products.gallery`) — register via
  the file manager service so uploads land in the right collection
- Disk-aware: configure DigitalOcean Spaces / S3 in `config/filesystems.php`
  (kit injects the `spaces` disk during install)
- Frontend page lives at `resources/js/pages/Admin/FileManager/` — uses
  Spatie MediaLibrary under the hood via the `HasMediaCollections` trait
- Trash retention: schedule `php artisan file-manager:purge-trash` (or pass
  `--days=N`) to permanently delete expired trash items
- Share links have create/revoke audit coverage on the activity log

### Activity & Audit Log

- Powered by `spatie/laravel-activitylog`; the kit sets its required config
  keys at runtime (`config/activitylog.php` is no longer published)
- Models log automatically when they use the `HasActivityLogging` trait
- A dedicated `audit` channel additionally records: role↔permission pivot
  changes, Settings changes (key names only — values are never logged),
  ApiClient/ApiToken create/revoke, share-link create/revoke, and
  ContentLanguage CRUD
- The activity logs panel at `/admin/activity-logs` is filterable / browsable

### Settings panel

- Groups defined in `config/settings.php` (general / auth / mail / storage /
  file-manager…). Add a key there and the UI renders the field automatically
- `sensitive_keys` in the same file are encrypted at rest and masked in logs;
  `sk:update` NEVER overwrites this file
- Backed by a settings table; values cached and accessed via `setting('key')`

### Definitions

- DB-backed enums shared between forms and tables. Two consumers:
  `FB.select().definitionOptions('key')` and
  `DB.column().tag('definition').tagKey('key')`
- Fetched once via `useDefinition()` and cached client-side; the server cache
  invalidates immediately on definition save/delete/restore
- Add new definitions via the seeder or the Definitions admin page

### OAuth2 API (Laravel Passport)

- Personal access tokens, authorization code, client credentials, device flow
- Token TTLs configured in `config/starter-kit.php` under `passport.*`
- Optional scopes: populate `passport.scopes` then attach `middleware('scope:foo')`
  to API routes you want restricted
- Client secrets are single-reveal; ApiClient/ApiToken lifecycle is audit-logged

### Theme system (v13.6.0+)

- Active theme selected by `VITE_SK_THEME` (`main` by default; `custom` for
  the opt-in override theme)
- CSS lives in a slot tree under `resources/css/theme/{main,custom}/` — every
  cascade layer (fonts, base, tokens, auth, per-component, utilities) is an
  individually overridable slot; an absent override falls back to the base
- `resources/js/theme/custom/preset.ts` can replace the PrimeVue preset
- `_active.css` is generated by the vendor `skTheme()` vite plugin — never
  edit it by hand
